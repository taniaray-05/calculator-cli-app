# Calculator CLI App

## Description
A simple command-line calculator built using Python. It supports addition, subtraction, multiplication, and division.

## Technologies Used
- Python
- VS Code
- Terminal

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Exit option
- Handles division by zero

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python calculator.py
